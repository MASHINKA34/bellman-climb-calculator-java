# Набор крейсерской высоты — алгоритм Р. Беллмана

Программа рассчитывает **оптимальную программу набора крейсерской высоты**
методом динамического программирования Р. Беллмана: строит сетку состояний
«высота — скорость», обратной прогонкой находит функцию Беллмана и восстанавливает
оптимальную траекторию набора.

Написана на Java. Веб-интерфейс открывается и на компьютере, и на телефоне.

---

## Постановка задачи

**Состояние** — пара (высота `H`, истинная скорость `V`).
**Этап** `k` — переход с высотного уровня `H_k` на следующий уровень `H_k+1`.
**Управление** — выбор скорости на новом уровне.

Стоимость перехода считается энергетическим методом. Энергетическая высота

```
Hэ = H + V² / (2g)
```

растёт со скоростью

```
dHэ/dt = V·(P − Q) / (m·g)
```

где `P` — располагаемая тяга, `Q` — лобовое сопротивление. Время перехода берётся
интегрированием `dt = dHэ / (dHэ/dt)` по правилу трапеций, расход топлива — как
средний секундный расход, умноженный на время участка.

**Уравнение Беллмана:**

```
f_N(i) = 0                                       — крейсерская высота достигнута
f_k(i) = min по j [ c_k(i, j) + f_k+1(j) ]       k = N−1, …, 0
```

Обратная прогонка даёт функцию `f` и оптимальное управление, прямой проход
по запомненным управлениям восстанавливает траекторию набора.

### Критерии оптимальности

| Критерий | Что минимизируется |
|---|---|
| `FUEL` | расход топлива на наборе, кг |
| `TIME` | время набора, с |
| `COST_INDEX` | приведённые затраты: топливо + стоимость времени |

### Учитываемые ограничения

- минимальная скорость по сваливанию `Vmin = k · V_св` (растёт с высотой);
- максимальная скорость — меньшее из ограничений по числу Маха и по приборной скорости;
- избыток тяги обязан быть положительным (иначе набор физически невозможен);
- минимально допустимая вертикальная скорость `Vy`;
- предельное изменение скорости за один шаг по высоте;
- необязательное закрепление конца набора за заданным крейсерским числом Маха.

### Расчётные модели

- **Атмосфера** — стандартная (ГОСТ 4401-81 / ISA) до 20 000 м: тропосфера с градиентом
  0,0065 К/м и изотермическая стратосфера.
- **Аэродинамика** — квадратичная поляра `Cx = Cx0 + A·Cy²`.
- **Тяга** — `P = P₀ · Δⁿ · (1 − k_M·M)`.
- **Удельный расход** — `Ce = Ce₀ · √(T/T₀) · (1 + k_Ce·M)`.

### Принятые допущения

- Масса самолёта в пределах одного расчёта постоянна. На наборе выгорает порядка 2 % взлётной
  массы, поэтому влияние на результат невелико; при желании массу можно задать средней по набору.
- Набор считается квазиустановившимся, разворотов и ветра нет.
- Все скорости — истинные (TAS); приборная выводится справочно как `V·√Δ`.

## Структура проекта

```
bellman-climb-calculator-java/
├── core/                     ядро расчёта — чистая Java, ноль зависимостей
│   └── src/main/java/ru/mashinka/bellman/core/
│       ├── atmosphere/Atmosphere.java        стандартная атмосфера
│       ├── model/Aircraft.java               данные самолёта
│       ├── model/ClimbTask.java              условия задачи и параметры сетки
│       ├── model/Criterion.java              критерии оптимальности
│       ├── perf/FlightPerformance.java       тяга, поляра, расход, скороподъёмность
│       └── dp/BellmanSolver.java             ← сам алгоритм Беллмана
└── web/                      веб-интерфейс на Spring Boot
    ├── src/main/java/ru/mashinka/bellman/web/api/ClimbController.java
    └── src/main/resources/static/            форма, графики, таблицы
```

Модуль `core` намеренно собран **без единой внешней зависимости** и на уровне языка Java 17 —
его можно целиком перенести в Android-проект, не меняя ни строчки.

## Как запустить

Нужны JDK 17 или новее и Maven.

### Сборка и запуск

```bash
mvn clean package
```

```bash
java -jar web/target/bellman-web-1.0.0.jar
```

Затем открыть <http://localhost:8090>.

### Запуск при разработке

```bash
mvn install -DskipTests
```

```bash
mvn -pl web spring-boot:run
```

### Другой порт

```bash
java -jar web/target/bellman-web-1.0.0.jar --server.port=9000
```

### Только тесты ядра

```bash
mvn -pl core test
```

## Как открыть с телефона

Сервер слушает все сетевые интерфейсы, поэтому телефон в той же сети Wi-Fi
открывает калькулятор напрямую.

1. Узнать адрес компьютера в локальной сети:

```bash
ipconfig
```

   Нужна строка «IPv4-адрес» вида `192.168.х.х`.

2. На телефоне открыть `http://192.168.х.х:8090`.

3. Если страница не открывается — брандмауэр Windows блокирует входящие соединения.
   Разрешить порт (выполнить в PowerShell от администратора):

```powershell
New-NetFirewallRule -DisplayName "Bellman 8090" -Direction Inbound -LocalPort 8090 -Protocol TCP -Action Allow
```

В браузере телефона страницу можно добавить на рабочий стол — она откроется как обычное
приложение. Расчёт при этом идёт на компьютере, то есть нужна связь с ним.

> **Автономная работа на телефоне пока не сделана.** Чтобы калькулятор считал без сети,
> нужен либо Android-клиент поверх того же модуля `core`, либо перенос расчёта в браузер.
> Ядро специально отделено от веба именно ради этого шага.

## Проверка расчёта

В модуле `core` 22 теста, среди них:

- сверка стандартной атмосферы с табличными значениями ГОСТ 4401-81;
- совпадение решения динамического программирования с **полным перебором** всех
  траекторий на мелкой сетке — прямая проверка того, что найден именно оптимум;
- совпадение значения функции Беллмана `f₀` с затратами по восстановленной траектории;
- проверка, что режим «по времени» действительно быстрее, а «по топливу» — экономичнее;
- корректный отказ, когда крейсерская высота лежит выше практического потолка.

Контрольный результат при исходных данных по умолчанию (условный среднемагистральный
самолёт, 70 т, набор 0 → 11 000 м, критерий «минимум топлива»):

| Показатель | Значение |
|---|---|
| Время набора | ≈ 19 мин 46 с |
| Расход топлива | ≈ 1425 кг |
| Дальность набора | ≈ 238 км |
